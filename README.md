# Лабораторные работы по курсу «Системное программное обеспечение» (СПО), 2026

Репозиторий с реализацией лабораторных работ по курсу СПО — системное программирование в Linux и Windows: процессы и IPC, сборка и статические библиотеки, плагины и динамические библиотеки, низкоуровневый файловый ввод-вывод, работа с памятью и отладка.

Тексты заданий и варианты — в PDF рядом с репозиторием: `Задания_на_ЛР_по_курсу_СПО_2026.pdf`.

Код пишется **без использования агентных ИИ** (исключения — только `README.md`, `CONTRIBUTING.md` и лицензионные правки в коде); каждый запрос на слияние проходит проверку понимания кода автором. Подробнее — в [lab1/CONTRIBUTING.md](lab1/CONTRIBUTING.md).
